# 실험 기록

Risk마다 최소 한 번 깨뜨리고, 고치고, 다시 잽니다. 파일 이름은 `E01-<실험-요약>.md` 형식입니다.

| 번호 | 실험 | 관련 Risk | Before → After |
|---|---|---|---|
| - | 아직 없음 | | |

## 작성 형식

```markdown
# E0N: <실험 제목>

- **날짜**: YYYY-MM-DD
- **관련 Risk**: R1
- **관련 ADR**: ADR-000N

## 가설
## 환경 (머신, 인프라, 데이터, 도구, 스크립트)
## 1차 측정 (Before)
## 원인 (로그, 쿼리, 그래프 근거)
## 개선 (커밋·PR 링크)
## 2차 측정 (Before / After 표)
## 결론과 남은 문제
```
