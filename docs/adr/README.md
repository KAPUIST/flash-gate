# ADR (결정 기록)

기술이나 설계를 고를 때마다 한 개씩 씁니다. 파일 이름은 `0001-<결정-요약>.md` 형식입니다.

| 번호 | 결정 | 상태 | 관련 Risk |
|---|---|---|---|
| - | 아직 없음 | | |

## 작성 형식

```markdown
# ADR-000N: <결정 제목>

- **상태**: 제안 / 채택 / 폐기 / ADR-000M으로 대체
- **날짜**: YYYY-MM-DD
- **관련 Risk**: R1

## 문제
## 선택지 (최소 2개, 장점·단점 표)
## 결정
## 이유 (실험 결과 링크)
## 감수하는 것
```
